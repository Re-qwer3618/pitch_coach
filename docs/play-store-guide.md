# Google Play 스토어 출시 가이드

이 앱을 Play 스토어에 올리기 위해 **코드 쪽 준비는 끝나 있습니다.** 아래 순서대로 진행하세요.

| 준비 항목 | 상태 |
|---|---|
| 앱 ID `com.pitchcoach.pitch_coach` (출시 후 변경 불가) | ✅ |
| 대상 API 36 (Play 최신 요건 충족), 최소 Android 7.0 (API 24) | ✅ |
| 권한: 마이크(RECORD_AUDIO) 하나 · 인터넷 권한 없음 | ✅ |
| 16KB 페이지 크기 정렬 (Android 15+ 요건) | ✅ 확인 완료 |
| 업로드 키 서명 설정 (`android/key.properties`) | ✅ 설정됨 → **키는 직접 생성** |
| AAB 빌드 스크립트 `tools/build_release.ps1` | ✅ |
| 앱 아이콘 (적응형 포함) / 스토어 아이콘 512 / 그래픽 이미지 1024×500 | ✅ `store/` |
| 개인정보처리방침 | ✅ `docs/privacy-policy.md` |
| 스토어 설명 문구 | ✅ 아래 |
| 휴대폰 스크린샷 (2장 이상) | ⬜ **직접 촬영 필요** |

---

## 1단계. 업로드 키 만들기 (처음 한 번)
```
powershell -ExecutionPolicy Bypass -File tools\create_upload_key.ps1
```
- 이름과 비밀번호를 입력하면 `H:\dev\keys\upload-keystore.jks`와 `android\key.properties`가 만들어집니다.
- **키 파일(.jks)과 비밀번호를 USB·클라우드 등에 반드시 백업하세요.** 이후 모든 업데이트에 필요합니다.
- 두 파일 모두 `.gitignore`에 들어 있어 GitHub에 올라가지 않습니다. 절대 공유하지 마세요.

## 2단계. AAB 빌드
```
powershell -ExecutionPolicy Bypass -File tools\build_release.ps1
```
테스트 → 빌드 → 서명 확인 후 `build\app\outputs\bundle\release\app-release.aab`가 만들어집니다.

> 업데이트할 때마다 `pubspec.yaml`의 `version: 1.0.0+1`에서 **`+` 뒤 숫자를 1씩 올리세요** (예: `1.0.1+2`). 같은 번호는 다시 올릴 수 없습니다.

## 3단계. Play Console 개발자 계정
1. https://play.google.com/console 에서 개발자 계정 생성 (등록비 **US$25, 1회**)
2. 본인 인증(신분증) 및 연락처 인증
3. ⚠ **2023년 11월 이후 만든 개인 계정**은 프로덕션(전체 공개) 출시 전에
   **비공개 테스트에 테스터 12명 이상이 14일 연속 참여**해야 프로덕션 신청이 가능합니다.
   가족·친구의 Gmail 12개를 미리 모아 두세요.

## 4단계. 앱 만들기 & 스토어 등록정보
Play Console → **앱 만들기** → 앱 이름 `음치탈출`, 기본 언어 한국어, 앱 / 무료.

내 목소리 음정을 실시간으로 보고, 피아노로 듣고 따라 부르며 음치를 탈출해요!

**자세한 설명** (4000자 이내)
```
🎤 노래할 때 음이 맞는지 모르겠다면? 음치탈출이 눈으로 보여 드려요!

음치탈출은 마이크로 들어온 목소리의 음정을 실시간으로 분석해서
지금 내는 음이 무엇인지, 얼마나 정확한지 피아노 건반 위에 보여주는 노래 연습 앱이에요.

■ 실시간 음정 분석
· 지금 내는 음을 계이름(도레미)과 음이름(C4, G4…)으로 바로 표시
· 튜너 게이지로 음이 높은지 낮은지 한눈에 확인
· 흘러가는 음정 그래프로 내 목소리의 흐름을 확인

■ 피아노로 배우는 음감
· 건반 위 커서로 내 목소리 위치를 표시 — 음 사이에 걸치면 커서도 건반 사이에!
· 건반을 누르면 피아노 소리가 나고 그 음이 목표 음이 돼요
· "조금 더 높게 ↑", "목표 음 성공! 🎯" 안내를 따라 음을 맞춰 보세요

■ 노래 연습 & 채점
· 도레미 음계, 도미솔 도약, 비행기, 학교종, 작은별, 환희의 송가, 징글벨 수록
· 피아노로 멜로디를 먼저 듣고 따라 부르기
· 다 부르면 일치율(%) 점수와 음표별 비교, 맞춤 피드백 제공
· 음표를 누르면 정답 음과 내가 부른 음을 피아노 소리로 비교해 들을 수 있어요
· 남성처럼 한 옥타브 낮게 불러도 자동으로 옥타브를 맞춰 채점해요

■ 내가 부르고 싶은 노래 추가
· 계이름을 입력하거나 피아노 건반을 눌러서 나만의 연습곡을 만들 수 있어요
· 가사를 넣으면 한 글자씩 음표에 자동으로 붙어요

■ 안심하고 쓰세요
· 목소리는 기기 안에서만 분석되고 녹음·전송되지 않아요
· 회원가입, 광고, 인터넷 연결이 필요 없어요

조용한 곳에서 휴대폰을 입에서 20~30cm 떨어뜨리고 불러 보세요.
오늘부터 음치 탈출! 🎶
```

## 5단계. 앱 콘텐츠 (정책 설문)
| 항목 | 답변 |
|---|---|
| 개인정보처리방침 URL | `https://github.com/Re-qwer3618/pitch_coach/blob/main/docs/privacy-policy.md` |
| 광고 | 광고 없음 |
| 앱 액세스 권한 | 모든 기능을 제한 없이 사용 가능 (로그인 없음) |
| 콘텐츠 등급 | 설문에서 폭력·성적 콘텐츠·도박 등 모두 "아니요" → 전체이용가 예상 |
| 타겟층 | **13세 이상** 권장. 13세 미만을 포함하면 '가족 정책' 추가 심사를 받습니다(데이터 수집이 없어 통과는 가능하지만 절차가 늘어남) |
| 뉴스 앱 / 정부 앱 / 금융 기능 | 아니요 |
| 건강 앱 | 아니요 |

### 데이터 보안(Data safety) 답변
- **앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요? → 아니요**
  - 근거: 마이크 오디오는 기기에서만 실시간 처리되고 기기 밖으로 전송되지 않습니다.
    Google 정책상 "기기에서만 처리되고 전송되지 않는 데이터"는 수집으로 보지 않습니다.
- 데이터 암호화 / 삭제 요청 항목: 수집 데이터가 없으므로 해당 없음

## 6단계. 테스트 → 출시
1. **테스트 및 출시 → 테스트 → 비공개 테스트**(또는 먼저 내부 테스트) → 트랙 만들기
2. 테스터 이메일 등록 → **새 버전 만들기** → `app-release.aab` 업로드
   - "Play 앱 서명" 사용 동의 (기본값, 권장)
   - 출시 노트 예: `첫 출시: 실시간 음정 분석, 피아노 연습, 노래 7곡, 내 노래 추가`
3. 테스터에게 참여 링크 공유 → 14일간 유지 (개인 계정 요건)
4. **프로덕션 액세스 신청** → 승인 후 프로덕션 트랙에 같은 AAB로 출시
5. 심사는 보통 수일(첫 출시는 최대 1~2주) 걸립니다.

## 업데이트할 때
1. 코드 수정 → `pubspec.yaml` 버전 올리기 (`1.0.1+2`)
2. `tools\build_release.ps1` 실행
3. Play Console에서 새 버전 만들기 → AAB 업로드
